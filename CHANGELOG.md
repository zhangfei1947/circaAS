# Changelog

## 0.1.0 — initial research prerelease

- Installable Python package and CLI; repository name circaAS, package name circadian-as.
- Fixed-24h beta-binomial model with pilot-99 bias-corrected null bootstrap.
- Strict rMATS count import, effective-length adjustment and experiment intercepts.
- Frozen coverage rules and four distinct outcome states.
- Per-event diagnostics, deterministic seeds, source/output hashes and PSI/depth plots.
- Continuous BLN sensitivity engine reserved but not implemented.
- 22 tests and development-data validation; no genome-wide FDR certification.
- Portable synthetic example and GitHub Actions package checks.
